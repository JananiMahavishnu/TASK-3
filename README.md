# Task 3 - SQL for Data Analysis

Objective

The objective of this task is to use SQL queries to extract, manipulate, and analyze structured data from a database. The task focuses on performing data analysis using various SQL operations and understanding how databases are used for business insights.

Tools Used

* SQLite
* DB Browser for SQLite
* GitHub

Dataset

* Sample Superstore Dataset

SQL Concepts Covered

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* Aggregate Functions (SUM, AVG)
* Subqueries
* Views
* INNER JOIN
* LEFT JOIN

Work Performed

* Imported the dataset into SQLite.
* Executed SQL queries to filter, sort, and analyze data.
* Calculated sales and profit metrics using aggregate functions.
* Created and queried SQL views.
* Performed joins between tables for relational analysis.
* Captured query outputs as screenshots for verification.

Repository Contents

* `task3_queries.sql` – SQL queries used for analysis
* `dataset.csv` – Dataset used in the task
* `screenshots/` – Query output screenshots
* `README.md` – Task documentation
